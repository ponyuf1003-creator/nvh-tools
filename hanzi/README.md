# 小小识字岛 🏝️

给 5-6 岁孩子的汉字学习应用（Phase 1：识字闭环）。纯静态页面，零后端，放到个人网站任意子目录即可运行。

## 功能

- **1000 字字库**：按部编版教材顺序（一年级上 300 + 一年级下 400 + 二年级上前 300），每字含拼音、组词、前期字有例句和 emoji 图义
- **每日任务闭环**：复习到期字卡 → 学 3 个新字（可调）→ 小测验巩固
- **四步法学字**：听音认字 → 图义 → 组词/例句（点击朗读）→ 笔顺动画 + 手指描红（hanzi-writer）
- **遗忘曲线复习**：简化 SM-2，间隔 1/2/4/7/15/30 天，答错降级重来，全对毕业
- **游戏**：听音摘果子、描红闯关（都用学过的字出题）
- **激励**：每日任务得星星，15 颗星解锁一只小动物
- **家长中心**：摸底标记已认识的字（线下已学的 200 字在这里标）、进度统计、薄弱字、每日新字数设置、数据导出/导入

## 目录结构

```
index.html        孩子首页（今日任务入口）
learn.html        学新字
review.html       复习字卡
games.html        游戏入口
game-listen.html  听音摘果子
game-trace.html   描红闯关
parent.html       家长中心
css/ js/          样式与核心逻辑（core.js：数据/存储/SRS/语音）
data/chars.json   1000 字数据
data/strokes/     1000 个笔顺文件（hanzi-writer 格式）
tools/            字库生成脚本（gen.js + charlist.json）
legacy/           更早的单文件原型（保留备查）
```

## 打开方式

**直接双击 `index.html` 即可使用**，全部功能（含笔顺描红）都可用——字库和 1000 个字的笔顺数据都已打包进 `data/chars.js` 和 `data/strokes.js` 随页面加载。

部署到网站或本地起服务同样可以：

```bash
npx http-server . -p 4180
# 打开 http://localhost:4180
```

朗读语速可在「家长中心 → 设置 → 朗读语速」调节（默认慢速），并有试听按钮。发音质量取决于设备系统语音：iPad/iPhone 上是"婷婷"，Chrome 桌面版联网时会自动选更自然的 Google 普通话。

## 部署到个人网站

把整个目录上传到网站的一个子目录即可，例如 `https://你的域名/hanzi/`。全部资源都是相对路径。

## 使用建议

1. **第一天**：家长先打开「家长中心」，把孩子线下已认识的约 200 字标记为「已认识」（有按课文分组的一键标记）
2. **每天 10-15 分钟**：孩子打开首页，先复习、再学新字、最后玩一个游戏，三颗星到手
3. 进度存在浏览器 localStorage 里，**固定用同一台设备同一个浏览器**；定期在家长中心导出备份
4. 发音用的是系统自带语音（iPad/iPhone 上效果不错）；iOS 需要先点一下屏幕上的喇叭按钮才会出声

## 扩展字库

`tools/gen.js` 可重新生成 `data/chars.json`（需 Node，依赖 pinyin-pro、cnchar、cnchar-words、hanzi-writer-data）：

```bash
cd tools && npm i pinyin-pro cnchar cnchar-words hanzi-writer-data hanzi-writer
node gen.js ..
```

手工内容（组词 WORDS、例句 SENT、图义 EMOJI）都在 gen.js 顶部，直接往里加即可。
