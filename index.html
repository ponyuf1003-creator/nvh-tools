TOOLS

两款专业工具

针对汽车转向与整车 NVH 两个高频分析场景独立设计，互相补充。

NVH · 实时采集

NVH Waterfall

用手机麦克风替代专业传声器，路试现场实时生成 3D 瀑布图谱。 在没有 Head Acoustics 仪器的情况下，快速定位整车噪声阶次与频段。

  • 实时 STFT 瀑布图，频率分辨率可调 阶次跟踪叠加显示（需配合转速信号） 支持手机、平板、PC 多端运行 鸿蒙 / iOS / Android 浏览器全兼容 音频数据全程留在设备本地，不上传

EPS · 数据分析

EPS Analyzer

直接读取 .mf4 与 .mat 测试文件，替代 MATLAB 完成 EPS 电机电流谐波、 NVH 阶次、Bode 频响等核心分析，结果导出为 PNG / CSV。

  • MDF4 / MAT 文件直接解析，无需转换 FFT · THD · STFT · 阶次分析四合一 Bode 图 FRF 频响分析与 PT1/PT2 拟合 8极12槽 PMSM 谐波阶次自动标注 完全离线运行，公司数据安全可控
